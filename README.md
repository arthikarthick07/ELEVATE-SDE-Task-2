# CredVault – Certificate Issuing & Verification Platform

CredVault is a digital certificate management platform designed to simplify certificate requests, application tracking, certificate verification, and administrative certificate management.

## Features

- **Home Page:** Easy navigation to all platform features.
- **Request Certificate:** Submit certificate applications with personal details.
- **Track Application:** Check application status using an Application ID.
- **Verify Certificate:** Verify certificates using a unique Certificate ID.
- **Admin Login:** Restricted access to administrative features.
- **Manage Applications:** Issue or reject certificate applications.
- **Manage Certificates:** View and revoke issued certificates.
- **Responsive Design:** User-friendly interface across different screen sizes.

## Technologies Used

- Vite

## Installation and Setup

1. Clone the repository:

   `git clone https://github.com/arthikarthick07/ELEVATE-SDE-Task-2.git`

2. Navigate to the project folder:

   `cd ELEVATE-SDE-Task-2`

3. Install dependencies:

   `npm install`

4. Start the development server:

   `npm run dev`

5. Open the local URL displayed in the terminal.
